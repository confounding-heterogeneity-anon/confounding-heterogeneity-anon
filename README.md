# Reproducible code for "Confounding Heterogeneity in Multivariate Sensitivity Analysis for Observational Studies"

This repository contains four R files that, when run, reproduce the figures and data involved in the tables for the manuscript and supplementary file. Instructions for reproducing results from the main manuscript and supplementary file are below.

## Reproducible code for Design Sensitivity

Download the `Confounding Heterogeneity Reproducible Code, Design Sensitivity.R` file. Running the entire script will create a folder titled `Confounding_Heterogeneity_Design_Sensitivity` containing:
- a) .csv files reproducing the calculated / simulated (via Monte Carlo) design sensitivity & infimum design sensitivity values for all simulation settings in the main and supplementary files
- b) .png files reproducing the three subfigures shown in Figure 2 of the main text

## Reproducible code for Finite-sample Power

Download the `Confounding Heterogeneity Reproducible Code, Finite Sample Power.R` file. Running the entire script will create a folder titled `Confounding_Heterogeneity_Finite_Sample_Power` containing:
- a) .csv files recreating Table S4 in the supplementary file
- b) .png files recreating the finite-sample power figures in both the main text and supplementary file

## Reproducible code for Bahadur-Rosenbaum Slope

Download the `Confounding Heterogeneity Reproducible Code, Bahadur Efficiency.R` file. Running the entire script will create a folder titled `Confounding_Heterogeneity_Bahadur_Efficiency` containing:
- a) .csv files recreating the relative Bahadur efficiency and relative sample size required results reported in Table S5 in the supplementary file
- b) .png files recreating the Bahadur-Rosenbaum slope figures in both the main text and supplementary file

## Reproducible code for Periodontal Disease Application
Download the `Confounding Heterogeneity Reproducible Code, Application.R` file. Running the entire script will create a folder titled `Confounding_Heterogeneity_Application` containing:
- a) Two .csv files recreating the sensitivity values reported in the main text and supplementary file
